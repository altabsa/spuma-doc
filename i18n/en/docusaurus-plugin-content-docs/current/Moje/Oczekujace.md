# Pending

The **Pending** section contains documents that are currently in the approval process. They are visible only to users who currently have permission to approve a given document.

---

## Selecting Documents

Document selection works in the same way as in the [**Secretary**](../Sekretariat/sekretariat.md) section.

---

## Toolbar

At the top of the workspace, there is a **toolbar** that contains the following options in this section:

- **Refresh** – reloads the document list and includes the latest changes.
- **Document operations** – allows operations to be performed on the selected documents.

---

## Available Document Operations

In the **Pending** section, one main operation is available:

- **Approve selected**
  - After selecting one or more documents and choosing this option, the documents are approved.
  - An approved document automatically moves to the next stage:
    - it is sent to the **next users responsible for approval** if the process requires further steps,
    - or it is moved **to the appropriate location in the Repository** if the workflow has been completed.

This allows the approval process to continue without manually transferring documents.

# Approving a Single Document

In addition to selecting multiple documents and approving them in bulk, you can also **approve a single document directly from its view**.

A full description of this operation is available in the [workflow](../przetwarzanie-pojedynczego-dokumentu/Obieg.md) section.
