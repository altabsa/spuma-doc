# Recent

The **Recent** section contains documents that were **recently viewed by the user**. This allows you to quickly return to documents you have worked with recently without searching for them again.

---

## How Do Documents Appear in the "Recent" Section?

The list is populated **automatically** – each document opened in the detailed view is remembered and added to this section. There is no need to mark documents manually.
