# Favorites

The **Favorites** section contains documents that the user has marked as favorites. This makes it easier to quickly find frequently used or important documents without searching for them each time.

---

## Managing Favorites

Documents can be added to or removed from Favorites [**from the single document view**](../przetwarzanie-pojedynczego-dokumentu/pasek-narzedzi-dokumentu.md).
