# Reports

The **Reports** section provides access to predefined data reports. Reports in SPUMA can use data from both the application itself and external systems (e.g. **SAP** or other databases). They help analyze system activity and allow users to quickly check document lists, flow statuses, or access approvals.

---

## Standard Reports

The system provides **5 standard reports**:

**1. Pending Documents**  
**2. Document List**  
**3. Customer Documents**  
**4. [Access Approvals](./zatwierdzenia-dostepu.md)**  
**5. [Unadvises Documents](./Nieprzypisane-dokumenty.md)**

The first three reports can be **modified, hidden, or deleted** by an administrator.  
The system report (**Access Approvals**) is a permanent part of the system.

---

## Creating and Managing Reports

Reports cannot be created directly from the user application.  
New reports can only be created in the **SPUMA administration panel**.

- Reports are created by users with access to the administration panel.
- Custom reports can also be prepared by our team upon request.

Reports are written in **SQL** and can combine data from SPUMA and other databases (e.g. SAP).

---

## Using Reports

- Reports can be **opened, filtered, and viewed**.
- Report data can be **printed** or **copied** for further use (e.g. in a spreadsheet).
