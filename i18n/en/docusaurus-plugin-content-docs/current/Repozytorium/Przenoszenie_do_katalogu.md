### How to Move a Document to Another Directory?

**1. Select documents**  
In the column on the left side of the list, select one or more documents that you want to move.

**2. Select the "Move to Directory" operation**  
From the toolbar, open the operations menu and click **Move to Directory**.

![Move to Directory](/img/przenies1_en.png)

**3. Select the new Directory**  
In the displayed window, select the target Directory from the available list.

**4. Click the OK button**  
The documents are moved to the selected Directory and become visible in its contents.

![Move to Directory](/img/przenies2_en.png)
