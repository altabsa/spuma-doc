# Repository

The **Repository** section stores documents that have already been **processed and approved**. This is where documents are moved after the workflow is completed, making the Repository the knowledge base and archive of the SPUMA system.

In the workspace, documents and folders are displayed as **directory structures**, making it easier to navigate the Repository content.

![Repository](/img/repozytorium_en.png)

---

## Using the Repository

The Repository is not used only for storing documents – users can actively work with its contents, for example when quick access to previously processed files is required.

To find documents more efficiently, use the available [**search mechanisms**](../wyszukiwanie/wyszukiwanie.md).

---
## Navigating the Repository

To reach the target Directory, select the next folders in the Repository structure.

When you reach the target Directory, the **full path to the current folder** is displayed at the top of the workspace together with the **list of documents** stored in that folder.

![Repository](/img/repozytorium2.png)

:::tip[Efficient Folder Navigation]
You do not need to navigate through the Repository from the beginning to return to a specific folder. Click any folder in the path to quickly return to an earlier level.
:::

---

## Displaying Documents from Subdirectories

It is not always necessary to open each folder individually. In many cases, it is more convenient to display **all documents located in the current Directory and its subdirectories**.

To do this, use the **switch in the bottom-right corner**:

![Document expansion icon](/img/repozytorium3_en.png)

Enable the switch so that:

- the icon is **highlighted in blue**,
- the system displays the **complete list of documents** located in the current Directory **and all of its subdirectories**.

Example view with list mode enabled:

![Document list from subdirectories](/img/repozytorium4_en.png)

To return to the standard folder view, click the switch again – the highlight disappears and the Directory structure is restored.

---

## Available Operations

### **Move to Directory**

Allows you to change the document location in the Repository structure.

---

### **Delete**

The **Delete** option does not permanently remove the document from the system.

After using this function, the document is moved to **Trash**, from where it can later be restored or deleted by an administrator according to the system configuration.

This protects documents against accidental deletion.

---

The Repository is therefore the place where **all required documents are stored** and remain available for review, analysis, or later use.
