# Operations on Added Documents

In the **Secretary** module, after selecting documents, various operations are available for processing them.  
To perform an operation, select a document using the **checkbox** on the left side of the list, then choose the appropriate action from the **operations menu** on the toolbar.

![Operations on added documents](/img/operacje_na_dok_7_7_en.png)

---

## Available Operations

### Send to OCR

Processes the document using the OCR mechanism (text recognition).  
After the operation is completed, the document status changes to **sent to OCR**.

### Send for approval

Moves the document to the appropriate section according to the configured workflow in SPUMA.  
The document disappears from the Secretary list and proceeds to the next processing stage.

### Delete

Permanently deletes the document from the Secretary list.

### Remove references

Removes the association between the selected documents and entries in Daily correspondence.

### Link to documents

Copies links to all selected documents to the clipboard.  
After the operation is completed, you can paste the copied links, for example into a message or as attachments in other documents.
