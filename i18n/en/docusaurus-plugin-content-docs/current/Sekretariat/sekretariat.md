# Secretary

Secretary is a **private space for each user** where newly added documents waiting to be processed are displayed.

As long as a document remains in Secretary, it is visible only to its owner – other users do not have access to it.

This is where the further document workflow begins.

After opening this section, the user sees a list of documents ready to be processed and sent into workflow.

If there are currently no documents to process, a message indicating that there are no entries is displayed.

---

## Selecting Documents

On the left side of the list, there is a column with **checkboxes** that allow documents to be selected.

- You can select a **single document**.
- You can select **all documents at once** by clicking the checkbox in the list header.

The selected documents determine which items the operations from the **operations menu** will be performed on.

---

## Toolbar

At the top of the workspace, there is a **toolbar** that allows basic document operations to be performed:

- [**Add document**](/i18n/en/docusaurus-plugin-content-docs/current/Sekretariat/dodawanie-dokumentow.mdx) – opens the window for uploading files or creating a new document.
- **Refresh** – reloads the document list and includes the latest changes.
- [**Operations menu**](/i18n/en/docusaurus-plugin-content-docs/current/Sekretariat/operacje-na-dodanych-dokumentach.md) – displays a list of actions that can be performed on the selected documents, e.g. sending to OCR, sending into workflow, or deleting.

---

The Secretary section is a key area – document processing in SPUMA usually starts here.
