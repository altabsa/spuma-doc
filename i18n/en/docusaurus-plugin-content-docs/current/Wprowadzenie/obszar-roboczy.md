# Workspace

After logging in to SPUMA, the user is taken to the main **workspace**. By default, it displays:

- document status visualizations,
- reports with pending documents,
- key system indicators.

---

## Section View

After clicking any item in the **Main Menu** (e.g. **Secretary**, **Pending**, **Favorites**, or a Repository folder), the system opens a separate window in the workspace.

A bar with the name of the active section appears at the top. Below it, the following may be displayed:

- a list of documents in the selected category or folder,
- the message **No entries** if there are no documents,
- a **document to process** if one has been selected from the list,
- or reports.

### Example Document List

Each entry in the document list contains basic information that helps identify the document:

- **Document name** – the full name assigned on the **General** tab together with the unique identifier in parentheses,
- **Document class** – e.g. **Cost Invoice**, **Purchase Order**, **Other Documents**,
- **Document date**,
- [**Status**](/i18n/en/docusaurus-plugin-content-docs/current/przetwarzanie-pojedynczego-dokumentu/Status_dokumentu.md),
- for documents of the **Invoice** class, the list additionally displays the **Business Partner (BP)** (e.g. DOCUMENT20261002),
- ![New data available](/img/nowe-dane.png) – if new or modified data appears during work, a warning icon is displayed next to the document list. The message reads: **New data has appeared! Reload the document list.**

![Document list](/img/lista_dok2_7_3_en.png)

### Example Open Document

After clicking any document in the list, its details are opened in the workspace. You can view, edit, and perform operations on the document.

![Document preview](/img/podglad_dok_7_3_en.png)

After clicking the monitor icon for a document in the list, its details are opened in a new workspace tab. Multiple documents can be opened at the same time.

![Document preview](/img/podglad_dok2_en.png)
