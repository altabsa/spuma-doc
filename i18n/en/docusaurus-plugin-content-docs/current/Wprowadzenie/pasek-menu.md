# Menu Bar

The menu bar is the top section of the SPUMA interface. It is always visible and provides quick access to the main application functions. It contains the following elements:

| Icon | Element name | Description |
|------|----------------|------|
| ![menu-toggle](/img/menu-toggle.png) | Main menu expand/collapse button | Allows the side main menu (navigation) to be hidden or displayed. |
| ![system-name](/img/system-name.png) | Logo + database name + system version | Displays the system logo, the name of the active database (e.g. OEC Computers), and the system version (e.g. v7.0.8). Helps identify whether the user is working, for example, in a test or production environment. |
| ![search](/img/search-icon.png) | [Search](/i18n/en/docusaurus-plugin-content-docs/current/wyszukiwanie/wyszukiwanie.md) | Allows documents to be searched. |
| ![flag-icon](/img/powiadomienia_flaga.png) | Pending documents | Indicates documents that require approval or user action. Clicking redirects to the list of pending documents. |
| ![edoc-icon](/img/powiadomienia_edoc.png) | Electronic Documents | Notifications related to electronic documents. |
| ![alert-icon](/img/powiadomienia_alarm.png) | Alerts | Personalized notifications. |
| ![messages](/img/messages-icon.png) | [Messages](/i18n/en/docusaurus-plugin-content-docs/current/wiadomosci.md) | Internal messaging system between SPUMA users. |
| ![user](/img/user-icon.png) | [User Account](/i18n/en/docusaurus-plugin-content-docs/current/konto_uzytkownika/konto.md) | Access to account settings, user data, and the log out option. |
