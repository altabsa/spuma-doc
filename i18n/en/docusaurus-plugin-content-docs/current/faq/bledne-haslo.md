# Incorrect Password

**Reported Issue**

The user cannot log in. After entering the username and password, the following message appears: *"Incorrect password"*.

**Solution**

1. Check that the entered credentials are correct (case-sensitive). Verify both the username and password.
2. If you have forgotten your password, use the [**Remind Password**](/docs/konto_uzytkownika/odzyskiwanie-hasla) option on the login screen.
3. If password recovery is not possible, contact the administrator.
