# Error Messages After an Update

**Reported Issue**

After updating SPUMA, various error messages may appear in the web application, e.g.:

```text
Ae.fill is not a function
```

---

**Solution**

The issue may be related to data stored in the browser from a previous version of the application.

First, check whether SPUMA works correctly in incognito mode.

If the issue does not occur in incognito mode:

1. Clear your browser history.
2. Clear the browser cache.
3. Restart the browser.
4. Reopen the SPUMA web application.

If the issue persists, report the error to the administrator, including the displayed error message.
