# Cannot Find Posted Invoices in SAP

**Reported Issue**

The user reports that they cannot find or view invoices posted in SAP.

---

**Solution**

SPUMA usually **does not post invoices directly** – they are first added as **draft documents**.

1. In SAP, go to **Reports → Sales and Purchasing → Document Drafts**.
2. Select the **SPUMA** user to narrow the search.
3. Search for the required documents.
