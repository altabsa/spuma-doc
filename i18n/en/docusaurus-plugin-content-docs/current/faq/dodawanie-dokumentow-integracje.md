# Is Manual Entry the Only Way to Add New Documents?

**Reported Issue**

The user is concerned that all documents must be added manually, which is time-consuming.

**Solution**

No – in addition to manual entry, you can use integrations.

SPUMA supports automatic document retrieval from sources such as:

- email,
- KSeF (National e-Invoice System),
- other sources configured during implementation.

This allows documents to be added to the system without manual entry.
