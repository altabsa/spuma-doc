# Can New Fields Be Added in SPUMA?

**Reported Issue**

The user wants to know whether the set of document fields is fixed or can be extended.

**Solution**

Yes – new fields can be added, but only by the **SPUMA administrator**.

The administrator can:

- create additional fields,
- assign them to specific Document Classes,
- define how they are displayed and completed.

This allows the system to be customized to the company's requirements and different processes.
