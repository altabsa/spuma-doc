# How to Add Attachments to a Document?

**Reported Issue**

The user wants to attach additional files or documents to a selected document in SPUMA.

---

**Solution**

In SPUMA, attachments are **links to other documents stored in the system**.

### Adding a Document as an Attachment

1. Open the document you want to attach.
2. From the top menu, select **Link to document** and copy the link.
3. Open the document to which you want to add the attachment.
4. Go to the **Attachments** tab.
5. Click **Attach from clipboard**.
6. The document is added as an attachment.

For details, see [**Attachments**](../przetwarzanie-pojedynczego-dokumentu/Zalaczniki.md).

---

### Detaching Attachments

1. Go to the **Attachments** tab.
2. Select the checkbox next to the required file.
3. Click **Detach selected**.
4. Save the changes to make the operation permanent.

---

### What About Files Outside SPUMA?

SPUMA does not allow files from your local disk to be added directly as attachments.

However, you can:

- use **Edit Pages** in the document menu to **import additional pages** from a file,
- add **Comments** to such pages or elements (described in the [Comments](../przetwarzanie-pojedynczego-dokumentu/pasek-narzedzi-dokumentu#new-comment) section).

This allows you to associate additional information with the document, even if the file does not originate directly from SPUMA.
