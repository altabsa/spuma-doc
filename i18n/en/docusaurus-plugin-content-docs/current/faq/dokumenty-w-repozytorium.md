# How Do Documents Get to the Repository?

**Reported Issue**

The customer is concerned that documents must first be added to Secretary and then manually moved to the Repository.

**Solution**

No additional steps are required.

1. Add the document to SPUMA (from a file or as a new document).
2. Complete the required **flow and approval process**.
3. After authorization is completed, the document is **automatically moved to the appropriate directory in the Repository**.

There is no need to manually move documents from Secretary to the Repository – the system handles this automatically.
