# Are Documents from KSeF Available in SPUMA?

**Reported Issue**

The user wants to know whether invoices from the National e-Invoice System (KSeF) appear automatically in SPUMA or need to be retrieved manually.

**Solution**

SPUMA supports integration with **KSeF**.

1. The **Electronic documents → KSeF Integration** menu contains documents retrieved from KSeF.
2. From this section, you can add them to **Secretary**. They will then be displayed like any other document and can be processed further.
3. There is no need to manually download files from KSeF and upload them again to SPUMA – simply use the integration.

This feature allows documents from KSeF to be retrieved directly into the system and processed through the approval flow.
