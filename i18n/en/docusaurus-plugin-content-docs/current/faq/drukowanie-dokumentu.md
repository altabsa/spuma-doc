# Can I Print a Document Directly from SPUMA?

**Reported Issue**

The user wants to know whether they can print a document directly from SPUMA without downloading it to their computer.

---

**Solution**

Yes – you can print a document directly from the SPUMA application.

1. Open the document.
2. Click the **Operations menu** icon (three horizontal lines).
3. Select **Print**.
4. In the print preview window, configure:
   - **Page range** (from–to),
   - **Lines** (to include document lines),
   - **On one page** (lines and authorizations on one page),
   - **Print authorization** (includes the document flow).
5. Click **Download documents** – a PDF file will open in a new tab.
6. Print the document from your browser.

For details, see [**Document Toolbar → Print**](../przetwarzanie-pojedynczego-dokumentu/pasek-narzedzi-dokumentu.md#print).
