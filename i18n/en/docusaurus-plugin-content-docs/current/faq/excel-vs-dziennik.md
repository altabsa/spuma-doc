# How Does Recording Correspondence in Excel Differ from Using Daily correspondence in SPUMA?

**Reported Issue**

The user wants to know why they should use **Daily correspondence** in SPUMA instead of keeping a register in Excel.

**Solution**

An Excel register is a simple table – each user must update it manually, which can lead to errors or inconsistencies.

**Daily correspondence** in SPUMA provides additional capabilities:

- data is linked directly to documents,
- the system automatically records history and statuses,
- access is controlled by user permissions,
- information is always up to date and available in one place,
- records can be easily filtered and searched.

This makes the register more secure, accurate, and practical than manually entering records in Excel.
