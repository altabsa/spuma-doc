# Invoice Cannot Be Added to SAP

**Reported Issue**

The user attempts to add an invoice to SAP, but error messages appear and the document is not saved.

---

**Solution**

To add the invoice to SAP successfully, follow these steps:

1. **Check that all required fields are completed** – missing data may prevent the document from being saved.
2. **Check that there are no extra empty document lines** – an accidentally added empty line may prevent the invoice from being saved.
3. If the problem persists after these checks, **contact the SPUMA administrator** for assistance.
