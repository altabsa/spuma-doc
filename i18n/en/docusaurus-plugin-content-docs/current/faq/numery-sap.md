# Do I Need to Remember All SAP Document Numbers?

**Reported Issue**

The user is concerned that they need to remember all SAP document numbers to work in the system.

**Solution**

You do not need to remember SAP document numbers.

1. Use the [**search mechanism**](../wyszukiwanie/wyszukiwanie.md) in SPUMA – enter part of a name, number, date, or another document attribute.
2. The document's **Attributes** tab contains all data retrieved from SAP, including document numbers and references.
