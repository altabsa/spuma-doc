# What Is OCR Used for in SPUMA?

**Reported Issue**

The user wants to know what OCR does and whether it is required when working with documents.

**Solution**

OCR (Optical Character Recognition) is used to **recognize text in image and PDF files**.

As a result:

- the system automatically reads data from invoices and other documents,
- you do not need to enter field values manually,
- processing is faster and the risk of errors is reduced,
- documents are ready for further processing and approval sooner.

OCR is optional, but it significantly improves daily work in SPUMA.
