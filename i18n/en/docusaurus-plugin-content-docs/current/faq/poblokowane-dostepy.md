# Blocked Access When Using Remote Desktop

**Reported Issue**

The user cannot start SPUMA. The application does not work correctly when launched through a remote desktop environment (RemoteApp / terminal).

---

**Solution**

If SPUMA is launched through RemoteApp, Remote Desktop, or another external environment, **appropriate access permissions** must also be configured in that environment.

1. Contact the administrator to check and configure access to SPUMA on the terminal you are using.

Launching the application from an environment other than the local workstation requires separate permission settings.
