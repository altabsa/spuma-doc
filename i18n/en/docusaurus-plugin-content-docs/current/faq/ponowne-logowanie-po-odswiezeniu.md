# Do I Need to Log In Again Every Time I Refresh the Page?

**Reported Issue**

The user notices that they need to log in again after refreshing the page.

---

**Solution**

SPUMA provides an option to **remember your session**, which you can enable when logging in.

1. Enter your login credentials.
2. Select **Remember**.
3. Click **Log in**.

![Login](/img/faq1_en.png)

After completing these steps, refreshing the page **will not log you out**.
