# Disabling Selected Email Notifications

**Reported Issue**

The user receives too many email notifications, for example about document approval, and wants to reduce their number.

---

**Solution**

The user can choose which email notifications they receive.

To change the settings:

1. Click your initials in the top-right corner.
2. Select **Settings**.
3. Go to the **Email notifications** section.
4. Select only the notification types you want to receive.
5. Save your changes.

Available notifications include:

- **Authorization required**,
- **Document accepted**,
- **Rejected**,
- **Approved by all**.

For a detailed description, see the documentation:

[**User Settings → Email Notifications**](../konto_uzytkownika/ustawienia-uzytkownika.md#email-notifications)
