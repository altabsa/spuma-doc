# Can I Only Store Expense Invoices in SPUMA?

**Reported Issue**

The user is concerned that the system only supports expense invoices and is not suitable for other document types.

**Solution**

No – you can store various types of documents in SPUMA, including:

- sales and expense invoices,
- Excel files,
- contracts,
- business trip documents and other company documents.

It is important to **define appropriate document classes** during implementation so that the system can recognize and process these documents correctly.
