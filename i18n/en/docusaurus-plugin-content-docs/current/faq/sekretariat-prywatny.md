# Why Can't I See Documents Added to Secretary by Another User?

**Reported Issue**

The user notices that another person has added documents to Secretary, but these documents are not visible on their list.

---

**Solution**

This is expected system behavior.

1. **Secretary** is a **private workspace** – each user can only see their own documents.
2. Documents added by another user are not visible in your Secretary.
3. To share a document, send it through an **authorization flow** or place it in the **Repository**.
