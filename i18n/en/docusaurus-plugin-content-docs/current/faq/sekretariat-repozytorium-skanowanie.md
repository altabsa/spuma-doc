# If a Document Is in Secretary and Repository, Do I Need to Scan It Twice?

**Reported Issue**

The user notices that a document first appears in Secretary and later in the Repository. They are concerned that they need to scan and add it twice.

**Solution**

No – you only need to scan or add the document once.

1. The document first appears in **Secretary** – your private workspace, where you can complete its data and send it for approval.
2. After the entire approval process is completed, the document is automatically moved to the **Repository** – there is no need to scan or add it again.

The system automatically handles moving the document between sections.
