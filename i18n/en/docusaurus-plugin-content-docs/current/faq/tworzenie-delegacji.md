# How to Create a Business Trip Document in SPUMA?

**Reported Issue**

The user wants to create business trip documents in SPUMA and select data (e.g. employee, vehicle) without entering everything manually.

**Solution**

Yes – this can be done by creating an appropriate Document Class.

During **system implementation**, a **Business Trip** Document Class can be configured with the required fields (e.g. employee, vehicle, date, purpose of travel).

To create a business trip document:

1. In **Secretary**, click **New document**, select **Create document**, and choose the **Business Trip** template.
2. Open the document and complete the data in the following tabs:
   - **General**,
   - **Attributes**,
   - **Lines**.
3. Save the document and, if required, send it for approval.

The **Business Trip** Document Class allows you to quickly prepare a document using predefined attributes and data from SAP, while completing all required information in the other tabs.
