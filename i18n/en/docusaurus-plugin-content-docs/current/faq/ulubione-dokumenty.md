# How to Save a Document for Quick Access?

**Reported Issue**

The user wants to quickly find important documents they plan to return to in the future.

---

**Solution**

In SPUMA, you can mark documents as **Favorites**.

1. Open the document you want to save.
2. Click the **Operations menu** icon (three horizontal lines) in the toolbar.
3. Select **Favorites**.
   - When the option is checked (✓), the document is added to Favorites.
   - When unchecked, the document is removed from the Favorites list.
4. All marked documents are available under **My documents → Favorites**.
