# Can I Recover Documents Deleted from Secretary?

**Reported Issue**

The user wants to know whether a document deleted from **Secretary** can be recovered.

---

**Solution**

No – deleting documents from Secretary in SPUMA is **permanent**.

1. After clicking **Delete**, the document disappears from the list and cannot be restored.
2. The document is not moved to a recycle bin or archive.
3. If the document was deleted accidentally, it must be uploaded to the system again.
