# Can I Add Multiple Documents to Secretary at Once?

**Reported Issue**

The user wants to know whether documents must be added individually or if multiple files can be selected at once.

**Solution**

Yes – you can add multiple documents at once.

1. Go to the **Secretary** section.
2. Click **New document**.
3. In the file selection window, select multiple files (hold **Ctrl** or **Shift** to select more than one).
4. Click **Open**.
5. Finally, click **OK** – all selected documents will be added at once.
