# What Happens If the First User Selects the Wrong Authorization Schema?

**Reported Issue**

The user is concerned that selecting the wrong Authorization Schema when sending a document for approval cannot be corrected.

**Solution**

There are two ways to resolve this issue:

1. **Rejecting the document** – the document returns to the first user, who can then select the correct Authorization Schema.
2. **Changing the Authorization Schema** – some users with appropriate permissions can change the schema during the approval process.

This ensures that selecting the wrong schema at the beginning does not block the entire process.
