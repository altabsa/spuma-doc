# User Account

The user account menu is located in the top-right corner of the application.  
Click your initials to expand the list of available options:

![User menu](/img/konto1_en.png)

- [**Settings**](./ustawienia-uzytkownika.md) – configuration of your account. Most account-related options are available here.
- **Help** – quick access to documentation and support.
- **System Information** – detailed information about the application version and SPUMA environment.

![SPUMA information](/img/konto2_en.png)

- **Log out** – ends the current session and securely logs the user out of the system.
