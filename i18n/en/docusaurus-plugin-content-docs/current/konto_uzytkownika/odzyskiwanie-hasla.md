# Password Recovery

If a user forgets their password, a new password can be set in two ways:

- using the e-mail address assigned to the account,
- by an administrator.

---

## Password Reset Using the E-mail Address Assigned to the Account - with User Hint

1. Enter your user name in the **User** field.
2. Click **Remind password**.

![Forgot password](/img/przypomnij_haslo_en.png)

3. In the **Password Recovery** window, the user name is filled in automatically.
4. Click **Send e-mail**.

![Password Recovery](/img/przypomnij_haslo2_en.png)

5. The system displays a message confirming that an e-mail with a password reset link has been sent to the address assigned to the account.

![Message sent confirmation](/img/przypomnij_haslo5_en.png)

6. Open the message sent to the e-mail address assigned to the account.
7. Click the password reset link.
8. Set a new password.
9. Log in to the SPUMA application again.

---

## Password Reset Using the E-mail Address Assigned to the Account - without User Hint

1. On the login screen, click **Remind password**.

![Password Recovery](/img/przypomnij_haslo3_en.png)

2. In the `User / e-mail address` field, enter:
   - the user name or
   - the e-mail address assigned to the account.

![Message sent confirmation](/img/przypomnij_haslo4_en.png)

3. Click **Send e-mail**.

4. The system displays a message confirming that an e-mail with a password reset link has been sent.
5. Open the message sent to the e-mail address assigned to the account.
6. Click the password reset link.
7. Set a new password.
8. Log in to the SPUMA application again.

:::warning
The message with the password reset link is sent only to the e-mail address assigned to the user account.

If the specified user name or e-mail address is not associated with any account, the system displays the message **The user does not exist in the system**.

![User does not exist in the system](/img/przypomnij_haslo6_en.png)
:::

If the message with the password reset link has already been sent, the system displays the message **The message has already been sent**.

![The message has already been sent](/img/przypomnij_haslo7_en.png)

---

## Password Reset by an Administrator

1. Ask the administrator to reset the password.
2. The administrator creates a new password and provides it through a secure channel.
3. Log in using the new password.
4. Set your own password directly in **User Settings**.
