# User Settings

The **Settings** option allows you to personalize your account and configure how you work in SPUMA.

To open it:

1. Click your initials in the top-right corner.
2. Select **Settings**.

![Settings window](/img/ustawienia1_en.png)

---

## User Data

- **Identifier** – user login (read-only).
- **Name/Surname** – personal data displayed in the system.
- **E-mail** – address used, among others, for notifications.
- **Signature** – content added **only to outgoing e-mail messages**.

---

## Comment Color

Each user can set their own comment color.

1. Click the square with the current color.
2. Select a color from the palette or click **Random** to assign a color automatically.

![Comment color](/img/ustawienia3_en.png)

This makes comments from different users easier to distinguish in a document.

---

## Password

You can change your access password in the **Old password** and **New password** fields.

- Enter the current password.
- Enter the new password.
- Click **OK** to save the change.

---

## E-mail Notifications

The options in this section define which document events will be sent to your e-mail address.

- You can select one or more options, e.g.:
  - **Authorization required**,
  - **Document approved**,
  - **Rejected**,
  - **Approved by all**,
  - **Authorization report**.

![E-mail notifications](/img/ustawienia2_en.png)

---

## During this period

You can select a user who will substitute for you during a specified period.

1. Select **During this period**.
2. Select the substitution start and end dates.
3. In the **Replaced by** fields, select a user.

This allows documents requiring authorization to be redirected to the selected person.

:::tip[Substitution and unplanned absence]
If a user did not configure a substitution before an unplanned absence, work in the system is not blocked.  
An administrator can assign a substitute at any time from the administration application.
:::

---

## Language and Appearance

- **Language** – select the application interface language.
- **Compact style** – enable this option to use a view with smaller spacing and display more content on the screen.

---

## Advice Visibility

Each user can customize the visibility of Advice entries:

- **All** – select to display all available Advice entries.
- **Only fit** – select to display only matching Advice entries.

---

## Saving Changes

- Click **OK** to apply the settings.
- Click **Cancel** to close the window without saving changes.

---

## Best Practices

- Change your password regularly.
- Select a unique comment color so your comments are easy to identify.
- Configure e-mail notifications so you do not miss documents requiring your decision.
- Configure a substitution before planned leave or a longer absence.
