# Document

The single document view in **SPUMA** opens after clicking a selected document from one of the lists, e.g. in **Secretary**, **Favorites**, **Recent**, or the **Repository**.  
By default, the **document workflow starts in Secretary** – this is where all newly added documents are placed and from where they can be opened for further processing.

The document window is divided into the following areas:

**1. Document preview** – the main part of the screen where the document content is displayed, e.g. an invoice scan or purchase order.

**2. [Document Toolbar](../przetwarzanie-pojedynczego-dokumentu/pasek-narzedzi-dokumentu.md)** – a set of tools used to manage the document preview and access the main operations menu.

**3. Side panel** – contains detailed information about the document divided into two sections:
- [**General**](../przetwarzanie-pojedynczego-dokumentu/ogolne.md) – basic document data, e.g. type, number, dates, owner, Directory,
- [**Attributes**](../przetwarzanie-pojedynczego-dokumentu/Atrybuty.md) – additional document data, e.g. Business Partner, dates, values.

**4. Tabs and functions panel** – a set of tabs used to work with the document:
- [**Flow**](../przetwarzanie-pojedynczego-dokumentu/Obieg.md)
- [**Lines**](../przetwarzanie-pojedynczego-dokumentu/Linie.md)
- [**OCR**](../przetwarzanie-pojedynczego-dokumentu/OCR.md)
- [**Attachments**](../przetwarzanie-pojedynczego-dokumentu/Zalaczniki.md)
- [**Dependent Documents**](../przetwarzanie-pojedynczego-dokumentu/Dokumenty-zalezne.md)

This panel also includes the **operations menu** and additional buttons.
