# Dependent documents

The **Dependent documents** tab displays documents to which the current document has been attached.

This allows you to quickly check which documents are linked to the currently opened document.

---

## Adding and Removing Documents from the List

The list is updated automatically.

If the current document is attached to another document, that document appears in the **Dependent documents** list. Similarly, when the attachment is detached, the dependent document is removed from the list.

---

## Viewing Dependent Documents

To open a dependent document:

1. Go to the **Dependent documents** tab.
2. If necessary, use the filters to find the required document.
3. Click the selected document in the list.

![Dependent documents list](/img/dokumenty_zalezne_en.png)

The selected document opens in the preview window.
