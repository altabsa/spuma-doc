# Document Status

Each document has an icon indicating its current status:

- ![Document ready for further processing](/img/ocr_nie.png) - the document is ready for further processing. It has either completed OCR processing or did not require OCR (e.g. a manually created document or a Word file).
- ![Document sent to OCR](/img/ocr_tak.png) - the document has been sent to OCR and is currently being processed. This status prevents the document from being sent for approval.
- ![Document pending approval](/img/dok_oczek.png) - the document is waiting for approval. It is displayed in the **Pending** section for the user responsible for approving it at the current stage of the authorization process.
- No icon - the document has been processed and is stored in the **Repository**. It was moved there without authorization.
- ![Approved document](/img/status2.png) - the document has been approved and is stored in the **Repository**.
- ![Rejected document](/img/odrzucone.png) - the document has been rejected.
- ![Document attachment](/img/zalacznik.png) - attachments have been added to the document. This icon is displayed next to the document status.
- ![External document](/img/dok_zew.png) - the document is linked to SAP Business One.
- ![Urgent document](/img/status_pilny.png) - the document has been marked as urgent. This indicator is displayed in the **Pending** document list.
- ![Document during substitution](/img/status_zastepwstwo.png) - the document is being processed by a user acting as a substitute. This indicator is displayed in the **Pending** document list.
- ![Locked document](/img/status_zablokowany.png) - the document is currently locked. This indicator is displayed in the **Pending** document list.
