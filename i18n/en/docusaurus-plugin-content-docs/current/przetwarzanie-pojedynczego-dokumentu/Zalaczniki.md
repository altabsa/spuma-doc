# Attachments

The **Attachments** tab is used to attach and detach files associated with a document.

:::danger[]
All attachments must originate from SPUMA. This means that a document must first be added to SPUMA before it can be attached to another document.
:::

---

## Attachment Operations

Two operations are available:

- **Attach from clipboard**
- **Detach selected**

![Attaching and detaching attachments](/img/zalaczniki_en.png)

---

## Attaching from Clipboard

The **Attach from clipboard** option allows you to add one or more documents as attachments using copied links.

### Attaching a Single Document

To attach an existing document:

1. Open the document you want to attach.
2. In the top menu, select **Link to document** and copy the link.
3. Open the document to which you want to attach the file.
4. Go to the **Attachments** tab.
5. Click **Attach from clipboard**.
6. The document is added as an attachment.

### Attaching Multiple Documents

To attach several documents at once:

1. Go to any document list.
2. Select the documents you want to attach.
3. From the **Operations** menu, select **Link to documents**.
4. Open the document to which you want to add the attachments.
5. Go to the **Attachments** tab.
6. Click **Attach from clipboard**.
7. All copied documents are added as attachments.

---

## Detaching Attachments

To remove an attachment from a document without deleting the file itself:

1. Go to the **Attachments** tab.
2. Select the checkbox next to the required file.
3. Click the menu icon and select **Detach selected**.

The attachment is detached, but the document remains in SPUMA.

---

## Saving Changes

After attaching or detaching an attachment:

1. Click **Save** in the top-right corner.
2. The operation is permanently applied to the document only after saving.
