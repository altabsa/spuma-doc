# Example Processes

This section contains three examples of the complete document processing workflow in SPUMA:

- [Document Added from a File](./przyklad-dokument-z-pliku.md)
- [Empty Document Created](./przyklad-dokument-pusty.md)
- [Document Retrieved from KSeF](./przyklad-dokument-ksef.md)

Each example shows the document processing steps:

1. Adding the document.
2. Completing the fields in the **General** and **Attributes** tabs.
3. Adding document lines.
4. Sending the document for approval.
5. Approving and posting the document.
