# Messages

SPUMA includes a built-in **Messages** module that works similarly to a simple chat.  
It allows you to communicate with other users and send links to documents.

---

## Opening Messages

1. Click the messages icon in the top bar.

![Messages icon](/img/wiadomosc1_en.png)

3. A panel with the list of conversations opens.

![Messages window](/img/wiadomosc2_7.8_en.png)

- If you click an existing chat, you can view its full history and continue the conversation.
- Enter a new message for the conversation participants in the **Enter message** field and click the **Send** icon.

:::tip[Document links]
You can paste **links to SPUMA documents** into messages – copy the link from the **document menu** and paste it into the message content.  
Clicking such a link opens the document in a **new tab**, providing quick access to it. You can open multiple documents at the same time – each one opens in a new tab.
:::

---

## Creating a New Message

To start a new conversation:

1. Click the **+** button.
2. The participant selection window opens.

![User selection](/img/wiadomosc3_en.png)

3. Select the person you want to contact from the list.

![User group](/img/wiadomosc4_en.png)

4. Click the **+** icon to add the person to the recipient group.

![User group – person added](/img/wiadomosc5_en.png)  ![User group – multiple people](/img/wiadomosc6_en.png)

- You can add more people to create a group.
- If you added someone by mistake, select the checkbox next to the person and click the trash icon to remove them.

After selecting the required users, click **OK**:

- If you have not previously exchanged messages with these users, a new chat is created.
- If a conversation already exists, its history opens and you can continue it.

---

## Searching Messages

Enter a phrase in the search field to search the chat history.

- **Result highlight** – the first matching message is **grayed out** (highlighted) to make it easier to locate.

![Search result – highlighted message](/img/wiadomosc10_7.8_en.png)

- **Next result** – click the search icon to move to the **next** message containing the phrase.
- **No results** – if no matches are found, the message **No results for the entered phrase** is displayed.

![Message search](/img/wiadomosc7_en.png)

---

## New Message Notifications

- When someone sends you a message, a red number indicating the number of new entries appears on the messages icon.

![Notifications](/img/wiadomosc8.png)

- In the conversation list, new messages are marked in red together with an icon showing the number of new entries.

![Message list with notifications](/img/wiadomosc9_7.8_en.png)
