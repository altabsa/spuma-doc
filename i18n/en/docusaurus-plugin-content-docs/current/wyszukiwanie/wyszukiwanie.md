# Search Mechanism

SPUMA provides two independent but complementary search mechanisms.

1. [Global Search](./wyszukiwanie_globalne)
2. [Contextual Search](./wyszukiwanie-kontekstowe)

---

## When to Use Which One?

| Goal | Global Search | Contextual Search |
|-----|------------------------|---------------------------|
| You are looking for "anything, anywhere" | ✅ Yes | ❌ No |
| You are searching only in the Repository | ❌ No | ✅ Yes |
| You want to search and edit immediately | ✅ Yes | ✅ Yes |

:::tip[Combining Global and Contextual Search]
The best results can be achieved by **combining both search mechanisms**.  
First, use **Global Search** to find all documents containing the specified phrase,  
then, while viewing the results, use **Contextual Search** to narrow the list by **status**, **class**, **Business Partner**, or other filters.  
This is a quick way to move from general results to specific documents.  
:::

---

## Example of Combining Search Mechanisms

1. Enter the document owner in Global Search and start the search.  
2. Go to the **Search results** section and open it.  
3. At the bottom, use **Contextual Filters** to narrow the results (e.g. **Authorization Status = Approved**, **Document Class**).  
4. Use **Sorting** to sort by date in descending order.  
5. Open the document and perform the required operations.
