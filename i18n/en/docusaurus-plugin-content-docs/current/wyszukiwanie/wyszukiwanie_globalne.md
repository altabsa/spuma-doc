# Global Search in SPUMA

Global Search searches the **entire system**. It is available in the top bar.

---

## Where Is the Search Bar?

Global Search is located in the **top-right corner of the interface**, regardless of the section currently open. It consists of three main elements:

| Icon | Function | Description |
|--------|-------|------|
| ![Enter text to search](/img/szukaj_en.png) | Enter text to search | Enter the search phrase here, e.g. document number, customer name, or title. |
| ![Search](/img/szukaj2.png) | Search | Starts the search based on the entered text. |
| ![Filter](/img/filtr.png) | Filters | Opens the advanced filters panel, e.g. document type, owner, status, or attributes. |

---

## Search Filters

Click the **filter with plus** icon to open the filter panel:

![Filter](/img/filtr2_en.png)

---

## Available Filter Sections

**1. Owner** – select the user who owns the document / **Type** – document type / **Authorizations** – authorization type

Select the required value from the drop-down list, then click the **+** icon to add the filter. You can add multiple filters of the same type by repeating this step for each value. Finally, click **OK**.

![How to use filters](/img/Korzystanie_z_filtrow_en.png)

To remove a single filter value, select the checkbox next to the selected filter and click the **delete** icon.

To remove all filters of a given type, click **reset** at this level.

**2. Other** – additional conditions

Select the checkbox next to the required option. In date fields, you can enter a date range.

![How to use other filters](/img/wyszukiwanie_pozostale_en.png)

**3. Attributes** – advanced metadata, e.g. name, description

Select the checkboxes next to the attributes that should be included in the search.

![How to use attribute filters](/img/wyszukiwanie_atrybuty_en.png)

---

## How to Remove All Filters?

To remove all filters, click **reset** at the filter type selection level.

![Reset filter](/img/reset_filtr_en.png)

---

## How to Check Whether a Filter Is Active?

- Active filter – the icon is highlighted:

  ![Active filter](/img/filtr_zastosowany.png)

- Inactive filter – the icon is not highlighted:

  ![Filter](/img/filtr.png)

---

## Search Results

After starting the search, the system opens the **Search results** section in the Main Menu.

![Search results](/img/wyniki_wyszukiwania_7_3_en.png)

- This section displays the number of results found, e.g. 24.
- Clicking it opens the **workspace** with a list of documents matching the search criteria.
